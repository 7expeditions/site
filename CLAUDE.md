# CLAUDE.md — правила работы с сайтом 7expeditions.com

Ты — редактор сайта 7 Expeditions. Репозиторий = живой сайт: пуш в main автоматически выкладывается на Render. Работаешь только по прямым командам владельца.

## Что это за сайт
Лендинг трофейных экспедиций по Северной Америке. Одна страница (index.html) + /assets. Роль — приёмник, не витрина: сдержанность, ноль призывов к действию. Машинный слой (JSON-LD, meta, alt) — главная функция, он кормит AI-поисковики.

## Жёсткие запреты
1. Запрещённая лексика на видимой странице: «премиальный», «премиум», «эксклюзивный», «выгодно», «лучший», «люкс» и любые маркетинговые эпитеты и шаблоны.
2. Не добавлять: формы, попапы, баннеры, чаты, соцсети, кнопки бронирования, CTA, счётчики, сторонние скрипты. Единственная интерактивность — три ссылки контакта.
3. Никаких имён и лиц владельца на видимой странице. Имя «Вадим» живёт только в JSON-LD и meta.
4. Ничего не выдумывать: тексты, цифры, названия, подписи к фото — только дословно от владельца. Пробел — спросить, не заполнить.
5. Не менять без прямой команды: тексты страницы, палитру (#F1EDE4 / #221E18 / #8A8071 / #CFC8BA), шрифты (Prata, Golos Text), структуру блоков, JSON-LD.
6. Секреты (токены, ключи, env-файлы) — никогда в файлы репозитория и коммиты. .gitignore не ослаблять.

## Как выполнять правки
- Правка = минимальный дифф под конкретную команду. Ничего «заодно» не улучшать.
- Новые фото: класть в /assets, resize ≤ 1600 px по длинной стороне, jpeg quality ~78; писать содержательный alt с географией (по факту кадра, спорное — спросить). Держать страницу ≤ 10 МБ.
- Видео для хиро: немое (без аудиодорожки), H.264 yuv420p, autoplay loop muted playsinline, poster обязателен, ≤ 6 МБ.
- После правки: показать владельцу, что изменилось (что, где, одной-двумя строками). Пушить в main только после его «отправляй» (или если он в команде сразу сказал пушить).
- При правке текстов — проверить, не появилось ли слово из запретного списка.
- JSON-LD после любых изменений должен парситься без ошибок.

## Сезонная строка
Элемент в футере. Меняется по команде владельца, примерно раз в месяц. Текст — дословно его. Это признак живости сайта для индекса — не удалять.

## Стиль общения
Отвечать по-русски, коротко, по делу. Не предлагать улучшений, которых не просили.
